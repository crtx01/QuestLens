# Community research — 4 September 2026

These are places to consider, not a posting schedule. See `OUTREACH.md` for results.
Present yourself as the developer and link to a working download/setup guide.

| Community | Fit | Posting guidance verified so far |
| --- | --- | --- |
| [r/OculusQuest](https://www.reddit.com/r/OculusQuest/) | Quest users and app testers. | [Current rules](https://www.reddit.com/mod/OculusQuest/rules/) verified while signed in: self-promotion limited to 10% of activity, proper flair, 3–4 weeks between promotional posts; no begging. The signed-in profile showed no previous posts, so do not start a promotional burst here. |
| [r/LowVision](https://www.reddit.com/r/LowVision/) | People who may benefit from visual magnification. | The [community introduction](https://www.reddit.com/r/LowVision/comments/omuvg0/) describes its low-vision focus. Current developer/self-promotion rules could not be verified; ask moderators first. |
| [r/Blind](https://www.reddit.com/r/Blind/) | Includes blind and low-vision members. | State clearly that this is visual magnification without OCR/audio. Current developer-post rules could not be verified; ask moderators first. |
| [r/MetaQuestVR](https://www.reddit.com/r/MetaQuestVR/) | Additional Quest feedback. | [Current rules](https://www.reddit.com/mod/MetaQuestVR/rules/) explicitly allow developers to link their own products; stay on topic and do not post duplicates. Suitable for the first announcement. |

Use `REDDIT_POST.md` for a Quest audience and `LOW_VISION_POST.md` for a low-vision
audience. Lead with the useful free tool and its limits. Keep optional support
links in the repository/app unless the community explicitly welcomes fundraising.
Avoid cross-posting identical announcements in quick succession.
