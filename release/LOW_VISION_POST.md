# Draft for a low-vision community

Title: QuestLens: a free magnifier for reading small text in Quest games

Hi, I'm c0rtex, and I'm involved in developing QuestLens. We developed this small
accessibility app for people with low vision who find text in VR games difficult
to read. Quest has accessibility settings, but we could not find a built-in
magnifier that solved this reading workflow on our Quest 3S. We'd like official
support to improve, and wanted to share a practical tool in the meantime.

It captures the current game image and opens a large 2D window where you can zoom
up to 8× and pan. Close it to return to the game. On the Quest 3S I've tested, a
double-tap on the headset opens and closes it, and the controller triggers zoom.
There are large on-screen controls and hover explanations too.

QuestLens magnifies a still image. It does not provide live zoom, OCR or spoken
text, so it is aimed at people who can use visual magnification. Images stay in
headset memory. All features are free.

This is an experimental sideloaded app. The optional gesture needs initial
developer/ADB setup, disables the native passthrough shortcut, and can be restored
in Settings. Other headsets and recovery after a full restart still need testing.

Download, source and written setup information: https://github.com/crtx01/QuestLens

If you use a Quest and visual magnification helps you, I'd welcome feedback on
readability and controls. Please don't feel you need to test it to join the discussion.

Optional support helps us maintain updates and create new accessibility tools
for people with low vision. The repository has details. All app features are free.
